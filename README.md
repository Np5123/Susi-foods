# Susi Foods - Healthy Ladoos Website

This is a simple, modern static website for Susi Foods, a business selling varieties of healthy ladoos.

## Features
- Homepage introducing the business
- Section showcasing ladoo varieties (with placeholder images)
- Contact/order form
- Mobile-friendly design

## How to Use
1. Open `index.html` in your browser to view the site.
2. Replace images in the `images/` folder with your actual product photos (use the same filenames or update the HTML).
3. Edit text and styles as needed to match your brand.

## Enhancements (Future)
- Add online ordering and payment
- Product management dashboard
- More interactive features
